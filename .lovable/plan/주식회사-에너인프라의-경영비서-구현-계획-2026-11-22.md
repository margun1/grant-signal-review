# 주식회사 에너인프라의 경영비서 — 구현 계획

설계 문서의 범위가 매우 넓어(14개 메뉴, 노션·구글 캘린더·카카오톡·이메일·공고 수집 연동) 한 번에 만들면 품질을 보장하기 어렵습니다. 아래처럼 단계별로 만들고, 각 단계가 끝나면 미리보기에서 확인하실 수 있게 하겠습니다.

## 1단계 — 기반 + 정부지원사업 (문서 1~6, 8~10장)
- Lovable Cloud 연결: 로그인(이메일·비밀번호, Google), 회원가입(초대 이메일만 허용), 비밀번호 찾기·새 비밀번호 설정, 이메일·계정 찾기 안내
- 역할: 관리자 / 실장 / 직원. 최초 가입자를 관리자로 지정하고, 관리자가 직원 초대·역할 부여
- 전역 디자인: 맑은 고딕, 오렌지·블랙·골드·에토프·아이보리 색상, 왼쪽 메뉴(모바일 접이식)
- 공고 목록 / 새 공고 분석 / 공고 상세
  - 공고 링크 입력 → 서버에서 본문·첨부 가져오기(Firecrawl 연결)
  - 실패 자료는 사유 표시 + PDF 추가 첨부 후 같은 공고에서 재개
  - AI가 신청 자격·POWERBOARD 적합성(우선 검토 / 추가 확인 / 낮은 우선순위), 지원 항목·지급 방식, 확인 필요 항목, 출처(문서명·쪽수) 표시
  - 실장이 대표님 확인 결과 기록(검토 중 / 진행 / 보류 / 미진행, 수정 시각)
  - 사업계획서 초안 PDF 업로드 → 문항별 검토표 + 복사 버튼, 회차별(1차·2차…) 보관, 중복 회차 방지
- 파일은 비공개 저장소, AI 호출은 서버에서만

## 2단계 — 경영 데이터 (7장 일부, 12장)
- 데이터 메뉴: 매출·원가·재고 엑셀 업로드(미리보기, 필수 열 확인, 재업로드 시 기간 교체로 중복 방지)
- 매출·상품, 수익성(완제품 원가 기준 매출총이익, 원가 누락 표시, 부품비 비교), 재고·발주(최소·목표 재고, 권장 발주량 = max(0, 목표−현재−미입고)), 꺾은선 그래프
- 경영현황 첫 화면: 오늘 처리할 일, 최근 1·3·7일 실적, 유튜브 영상(11장)
- 엑셀 내려받기

## 3단계 — 업무 관리
- 체크리스트(매일·매주 반복 자동 생성), 출퇴근(중복 방지, 수정 요청·관리자 승인 이력)
- 고객문의(C/S) 화면 + 홈페이지 문의 접수 주소, AI 답변 초안, 기기오류 관리
- 외부 미팅 예약 공개 페이지 + 내부 일정 달력

## 4단계 — 외부 연동 및 AI
- 구글 캘린더 연동(충돌 제외, 확정 시 등록), 노션 읽기 전용 연동, 회신 이메일 발송
- AI 비서 대화창(변경 작업은 확인 후 실행), 주간 AI 리포트
- 카카오톡 채널: 공식 연동 범위·계정 권한 확인 후 연결(계정 정보 필요)

## 진행 중 필요한 것

- 고객문의 전용 회신 이메일 주소, 카카오톡 채널 계정은 정해지면 알려주세요
